# О проекте

Это демонстрационный CRUD-сайт на FastAPI с PostgreSQL.
Реализован счётчик уникальных посетителей, простая авторизация по никнейму,
игра «Змейка» и AI-ассистент на основе RAG (Retrieval Augmented Generation).

## Технологии

- FastAPI — веб-фреймворк
- PostgreSQL — база данных
- SQLAlchemy — ORM
- ChromaDB — векторная база для RAG
- OpenAI — эмбеддинги и генерация ответов
- Nginx — reverse proxy
- Let's Encrypt — SSL сертификаты

## Как пользоваться

На главной странице можно добавлять, редактировать и удалять записи (CRUD).
Кнопка «Змейка» открывает мини-игру. Кнопка «AI-ассистент» открывает
чат, который отвечает на вопросы по содержимому этой базы знаний.

## Авторизация

Введите любой никнейм (до 30 символов), чтобы «войти». Ник хранится в cookie.
